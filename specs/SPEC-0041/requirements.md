## User Stories

- 以勾選決定映射及訓練使用的訊號，無需把角速度偽裝成加速度欄位。
- 同時選取兩類訊號後取得共同模型與單一碰撞事件判斷。
- 保存再開啟後保留訊號設定，舊加速度專案仍可使用。

## Requirements

| ID | Requirement |
|---|---|
| REQ-001 | 提供可同時勾選的 Accelerometer / Gyroscope，前者初始勾選，後者不勾選，不顯示預設勾選文字。 |
| REQ-002 | 每個已選訊號類別各自映射 XYZ，未選訊號不參與模型。 |
| REQ-003 | 選取的訊號參與共同訓練及單一碰撞判斷。 |

| REQ-004 | 成功完成 Mapping 後，依 IMU、訊號種類、raw/filtered 及 XYZ 角色記住最近一次成功映射的欄位名稱；僅本次程式執行期間保留，不持久化此暫存。 |
| REQ-005 | 下一個尚未設定 Mapping 的 recording 依相同欄位名稱自動帶入，不受欄位順序影響；缺少名稱的欄位留空。已有 Mapping 優先保留，取消或失敗不更新暫存。 |
