# Flow cost review

## Prepare workspace

The tabular adapter reads CSV/XLSX once and converts it to semantic numeric columns. The domain validates rows and interval partitions without framework objects. Plot rendering receives viewport-decimated copies; it must not copy all 10 million rows per gesture. Import preflight rejects over 50 recordings, over 1 million rows per recording, over 10 million total rows, or estimated peak memory above 60 percent of currently available RAM.

## Learn and qualify

The Qt event loop schedules one bounded background worker. The worker owns temporary numerical arrays and sends immutable, coalescible progress snapshots no slower than the 500 ms acceptance interval while measurable work advances. Candidate construction deduplicates equal tap counts. Feature matrices and replay operate in bounded chunks. Cancellation is checked between bounded kernels and before scheduling each candidate or fallback round.

The single-UI-thread candidate was rejected because it cannot satisfy navigation, progress, or cancellation behavior during numerical work. The selected UI-plus-worker composition follows SPEC-0001 REQ-019 and REQ-039. These are best-effort desktop workloads with measured percentile/bounded-responsiveness acceptance, not a real-time control scheduler; the collision 20 ms value is an offline replay gate.

SPEC-0013 adds no execution boundary. Fixed-grid mode dispatches exactly H selected
effective Histories times A selected alphas times N folds, with H at most six and A at
most five, then reuses existing Loss, fold selection and Qualification. It has no fine
search and therefore cannot exceed the existing optimized coarse candidate frontier for
the same N-fold setting. Optimized mode retains its current search path. This is a static
cost comparison only; existing Windows runtime evidence remains required for resource or
performance acceptance.

## Export profile

Header rendering is linear in the selected kernels' `9L` coefficients and coverage tuples. Each selected kernel is serialized independently with a stable `kNNN` default name. File output uses one user-selected folder, writes each file atomically, and preserves an existing file unless replacement is explicitly approved for that file.
